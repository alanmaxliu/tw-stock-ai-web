Taiwan Stock Watch

台股即時技術分析工具

從 GitHub Actions 更新的 40 檔熱門台股清單挑選標的，依最新價、均線、RSI、MACD、波動率與價格位置產生技術狀態觀察；若 JSON 不存在，會嘗試從外部公開資料源補抓。

可輸入任意台股代號；熱門提示由 GitHub Actions 依成交金額產生：ETF 前 20、個股前 20。

等待輸入股票代號。

使用限制

這是純前端工具，不會把查詢紀錄存到雲端。若已設定 Cloudflare Worker，會優先查詢即時報價；若未設定或查詢失敗，會改讀 GitHub Actions 產生的 JSON 與公開備援資料。此工具不做上漲機率、模型預測或保證獲利判斷，分析結果只供研究參考。
