# 台股 AI 技術分析網頁

純前端台股分析工具。使用者輸入單一股票代號後，網頁會讀取公開日線資料，使用 TensorFlow.js 與技術指標產生分析結果、PNG 圖表與 Markdown 報告。

## 功能

- 一次分析一個台股代號。
- 支援亮色、暗色與跟隨系統設定。
- 優先讀取 `data/stocks/{股票代號}.json` 靜態資料。
- 靜態資料不存在時，才嘗試外部公開資料源。
- 若瀏覽器允許讀取 TWSE MIS，會嘗試套用盤中報價。
- 可下載分析報告與 PNG 圖表。

## 資料更新

`data/tracked-symbols.json` 預設為空。若要讓 GitHub Actions 預先產生某些股票的靜態資料，請自行加入股票代號。

## 風險聲明

分析結果只供研究參考，不是保證獲利建議，也不是個人化投資建議。GitHub Pages 是靜態網站，外部資料源可能因 CORS 或服務限制而讀取失敗。日線資料以交易日收盤後資料為主；盤中報價只在資料源允許讀取時套用。
