# 台股即時技術分析網頁

這是一個公開的台股技術分析網頁。使用者可輸入台灣股票代號，查看公開行情資料整理出的技術分析結果、價格圖表與可下載報告。

## 功能

- 支援手動輸入台股代號。
- 提供熱門台股快速選擇清單。
- 顯示最新價、資料日期、技術分數、今日訊號與分析說明。
- 可下載 Markdown 分析報告與 PNG 圖表。
- 畫面會跟隨系統亮色或暗色設定。

## 資料與更新

- 分析資料來自公開行情資料與預存備援資料。
- 盤中可取得即時行情時，會優先顯示較新的盤中價格。
- 非盤中或即時行情暫時不可用時，會顯示最近可取得的收盤或備援資料。
- 熱門清單與部分備援資料會由排程定期更新。

## 使用限制

本工具只依公開價格資料與技術指標產生量化觀察，不包含模型預測、上漲機率或保證獲利判斷。分析結果只供研究參考，不是個人化投資建議。
